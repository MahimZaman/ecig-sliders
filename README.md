# Ecig Sliders

3 Custom sliders for showcasing products and images

## Installation and use

Place the `ecig-sliders` directory in `wp-content/plugins/` and activate **Ecig Sliders** from the WordPress Plugins screen.

With WooCommerce active, use `[ecig_product_slider]`, `[ecig_cat_slider]`, or `[ecig_banner_slider]` to display the corresponding slider.
